# 넘버 커넥트 (Number Connect)

숫자를 연결하여 점수를 얻는 퍼즐 게임입니다. 인접한 동일한 숫자 타일부터 시작하여 연속으로 같거나 두 배 값의 타일을 연결해 점수를 획득하세요!

실행주소1 : https://sigco3111.github.io/number-connect/

실행주소2 : https://dev-canvas-pi.vercel.app/

## 게임 규칙

1. **기본 규칙**:
   - 연결의 첫 두 블록은 같은 숫자여야 합니다.
   - 이후 블록은 이전 블록과 같거나 이전 블록의 두 배 값이어야 합니다.
   - 예: `2-2-4-8-8-16` 또는 `4-4-4-8-16`

2. **점수 시스템**:
   - 연결된 모든 타일의 숫자 합이 기본 점수가 됩니다.
   - 빠른 시간 내에 연속으로 조합을 만들면 콤보 보너스가 적용됩니다.
   - 콤보 보너스는 최대 2배까지 증가합니다.

3. **게임 종료**:
   - 더 이상 연결 가능한 타일이 없으면 게임이 종료됩니다.
   - 최종 점수와 점수 기록이 표시됩니다.

## 주요 기능

- **다채로운 타일**: 숫자에 따라 색상이 다르게 표시됩니다.
- **콤보 시스템**: 연속 조합 시 점수 보너스가 적용됩니다.
- **자동 저장**: 게임 상태가 자동으로 저장되어 브라우저를 닫았다가 다시 열어도 게임을 이어서 할 수 있습니다.
- **직관적인 UI**: 간단하고 직관적인 인터페이스로 누구나 쉽게 게임을 즐길 수 있습니다.

## 설치 및 실행 방법

### 필요 조건

- Node.js (v14 이상)
- npm 또는 yarn

### 로컬에서 실행하기

1. 저장소를 클론합니다:
   ```bash
   git clone [repository-url]
   cd number-connect
   ```

2. 의존성을 설치합니다:
   ```bash
   npm install
   # 또는
   yarn install
   ```

3. 개발 서버를 실행합니다:
   ```bash
   npm run dev
   # 또는
   yarn dev
   ```

4. 브라우저에서 `http://localhost:5173`을 열어 게임을 시작합니다.

### 배포하기

1. 프로젝트를 빌드합니다:
   ```bash
   npm run build
   # 또는
   yarn build
   ```

2. `dist` 폴더에 생성된 파일을 웹 서버에 업로드하거나 정적 호스팅 서비스(Netlify, Vercel 등)를 이용하여 배포할 수 있습니다.
